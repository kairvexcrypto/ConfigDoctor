# Приёмка на тестовом сервере

Статус: сценарий подготовлен, на живом Paper ещё не выполнен.

1. Установить итоговый JAR на чистый Paper 1.21.11 / Java 21. Проверить включение и наличие двух профилей.
2. `/cdoc check example` должен завершиться без ошибок; `/cdoc report` должен показать файл и время проверки.
3. В `example.yml` поставить `limits.players: 0`. Проверить код `MIN`. Вернуть 100.
4. Установить `mode: arena` без `arena.world`. Проверить код `REQUIRED` для `/arena/world`.
5. Вставить повторный ключ или оборванный список. Отчёт должен показать ошибку YAML и позицию без исходных значений.
6. Повредить `rules.yml`, вызвать reload. Исправные ранее загруженные правила должны продолжить работу. После исправления reload должен загрузить новый набор.
7. Проверить выдачу и отзыв каждого права через систему разрешений. Обычный игрок без прав не должен получить результаты.
8. Проверить выход игрока во время запроса: сообщение и отчёт не должны попасть в новую игровую сессию.
9. Проверить checkall с отсутствующим BlockJournal: ожидается NOT_FOUND для его файла и отдельный результат example.
10. Экспортировать отчёт, проверить Markdown, отсутствие значений из конфигурации и корректные русские символы.
11. Проверить повторные запросы нескольких операторов, ограничение очереди и штатное выключение сервера.

Проверку проводить на копиях конфигураций. После выполнения записать сборку Paper, версии зависимостей и фактические результаты; этот документ сам по себе не является подтверждением приёмки.
